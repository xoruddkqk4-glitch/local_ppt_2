# Local PPT 2

Local PPT 2는 텍스트·개요·PDF·엑셀 정보를 AI로 슬라이드 초안으로 변환하고, 오른쪽 16:9 캔버스에서 PowerPoint처럼 개체를 직접 편집할 수 있는 로컬 프레젠테이션 편집기입니다. 첫 화면은 Bauhaus 디자인으로 제공되며, 빈 슬라이드나 기존 Local PPT 프로젝트로 바로 시작할 수도 있습니다.

서버나 계정 없이 프레젠테이션을 만들고, 전체 작업 내용을 사람이 읽을 수 있는 JSON 기반 `.txt` 파일로 보관하는 것이 이 프로젝트의 목표입니다. 페이지의 내용과 이미지까지 하나의 파일에 저장되므로 다른 컴퓨터에서도 같은 프로젝트를 이어서 편집할 수 있습니다.

## AI 시작 화면

첫 화면은 아래 3줄 구조로 구성되어 있습니다. 각 줄은 같은 전체 가로 폭을 사용합니다.

1. **빈 슬라이드 불러오기**와 **txt 불러오기**: 새 편집기를 열거나 기존 Local PPT 프로젝트를 불러옵니다.
2. **공통 설정**: 슬라이드 장수와 ChatGPT·Claude API 키, 제공자별 모델을 선택합니다. 기본값은 ChatGPT의 `gpt-5.4-mini`와 Claude의 `claude-sonnet-5`입니다. OpenAI의 최신 최고 성능 모델 `gpt-5.6-sol`, 고성능 균형형 `gpt-5.6-terra`, 최신 저비용형 `gpt-5.6-luna`도 선택할 수 있습니다. 기존 저비용 모델 `gpt-5-mini`와 Claude의 `claude-haiku-4-5`도 제공합니다. 슬라이드 장수 영역과 API 키 영역은 서로 다른 배경색으로 구분되며, 같은 최소 높이를 유지합니다. API 키는 해당 생성 요청에만 사용되고 저장되지 않습니다.
3. **입력 방식**: 줄글 붙여넣기, 개요 붙여넣기, PDF 파일 업로드, 엑셀 파일 업로드 중 하나를 선택합니다. 줄글·개요를 선택하면 텍스트 입력칸이, PDF·엑셀을 선택하면 해당 파일 선택칸이 표시됩니다.

`AI로 슬라이드 만들기`를 실행하면 입력 내용을 선택한 ChatGPT 또는 Claude API에 슬라이드 생성 프롬프트와 함께 전송합니다. 버튼에는 입력 확인, PDF·엑셀 분석, AI 구성, 응답 확인, 편집기 적용 단계와 진행률이 동적으로 표시됩니다. AI는 제목, 부제목과 함께 슬라이드별 템플릿·개체 종류·레이아웃 및 실제 데이터가 담긴 JSON을 반환하며, 편집기는 이를 표지와 편집 가능한 본문 개체로 변환합니다. 생성된 모든 슬라이드는 기존 캔버스에서 텍스트·레이아웃·이미지·표·차트를 계속 편집해 완성할 수 있습니다.

AI는 각 슬라이드의 내용 관계를 분석해 개조식, 마인드맵, 개체형 중 적절한 템플릿을 선택합니다. 개체형에서는 비교·지표·표 등에 맞는 레이아웃, 과정·시간·관계에 맞는 다이어그램, 실제 숫자 데이터에 맞는 세로 막대·가로 막대·선·영역·원형 차트를 선택합니다. 엑셀 입력에서는 숫자 비교와 추이를 가능한 한 차트로 구성하며, 차트에는 원본에서 추출한 실제 숫자만 사용합니다.

AI 요청에서는 프레젠테이션 기획 규칙과 JSON 출력 규격을 시스템 프롬프트로 전달하고, 사용자가 붙여넣거나 파일에서 추출한 입력 원문만 별도의 사용자 메시지로 전달합니다. 입력 원문 안에 지시문처럼 보이는 문장이 있어도 프레젠테이션의 근거 자료로만 취급합니다.

AI 생성은 `index.html` 파일을 직접 열지 않고 `node server.js` 실행 후 `http://127.0.0.1:8765`에서 사용해야 합니다. 서버 또는 네트워크 연결에 실패하면 API 키를 유지해 오류를 확인한 뒤 다시 시도할 수 있습니다. 생성에 성공한 뒤에는 API 키를 자동으로 지웁니다. Anthropic 요청은 최신 Claude 모델에서 더 이상 지원하지 않는 `temperature`를 보내지 않습니다.

상단의 **첫 페이지로 돌아가기** 버튼을 누르면 현재 편집 내용을 유지한 채 이 시작 화면을 다시 열 수 있습니다.

## 편집기 구성

- **PAGE 01 — 표지:** 프레젠테이션 제목과 부제목을 편집하고, 필요하면 계층형 텍스트 항목을 추가하며 전체 디자인을 결정합니다.
- **PAGE 02 이후 — 본문:** 개조식, 마인드맵 또는 개체형 템플릿으로 내용을 구성합니다.
- **왼쪽 패널:** 디자인·템플릿 선택, 항목 추가·삭제, 이미지 삽입을 담당합니다.
- **오른쪽 캔버스:** 텍스트 직접 편집, 개체 선택·이동·크기 조절과 전체 화면 미리보기를 제공합니다.

## 디자인

하나의 프레젠테이션에는 하나의 디자인이 적용되며 PAGE 01에서만 변경할 수 있습니다.

| 디자인 | 특징 | 기본 강조색 |
|---|---|---|
| Bauhaus | 기하학, 삼원색, 강한 타이포그래피와 기능적인 그리드 | 파스텔 레드 |
| Claymorphism | 부드러운 파스텔 색상, 둥근 모서리와 입체적인 그림자 | 파스텔 핑크 |
| Neo-Brutalism | 굵은 검은 테두리, 고대비 원색과 단단한 그림자 | 고대비 레드 |
| Skeuomorphism | 실제 재질을 연상시키는 질감과 입체적인 UI | 코럴 레드 |
| Swiss Minimal | 넉넉한 여백, 엄격한 그리드와 절제된 색상의 미니멀 디자인 | 스위스 블루 |
| Swiss Grid Modern | 12열 그리드, 고대비 흑백과 데이터 중심의 정밀한 구성 | 시스템 블루 |
| Functional Bauhaus | 기능적인 비대칭 구성과 절제된 삼원색의 강한 타이포그래피 | 바우하우스 레드 |
| Soft Layered Minimal | 밝은 중성 배경, 낮은 채도와 부드러운 카드 깊이감 | 소프트 인디고 |
| Controlled Neo-Brutalism | 정돈된 굵은 테두리, 제한된 원색과 작은 오프셋 그림자 | 코럴 레드 |
| Tactile Product Minimal | 제품 UI를 닮은 정밀한 컨트롤과 금속성 중성색 | 인더스트리얼 블루 |

타임라인의 곡선·화살표와 `카드형 그리드(측면 강조)`의 세로선은 해당 디자인의 개조식 항목에 적용되는 강조색을 자동으로 공유합니다.

  - 영역형 차트

- 레이아웃·다이어그램·차트 종류를 바꿔도 기존 제목, 텍스트, 숫자, 표와 이미지를 유지하고 새 구조에 재배치
- 다이어그램 전환 시 기존 문구를 노드 순서에 맞게 배치하고, 차트 전환 시 표·텍스트에서 항목명과 숫자를 추출해 실제 데이터로 사용
- 차트 하단에 변환 전 원문을 함께 표시하고 다른 구조로 다시 전환할 때 원래 내용을 복원
- 캔버스에서 텍스트를 더블클릭해 직접 편집
- 텍스트 또는 표 셀 편집 중 `Alt+Enter`로 명시적인 줄바꿈 삽입
- 텍스트 색상, 좌·중·우 정렬, 글자 크기, 자동 맞춤 설정
- 글자 크기 입력은 숫자를 모두 입력한 뒤 `Enter`를 눌렀을 때 적용
- 모든 템플릿·레이아웃·다이어그램에서 동일 역할·위계 항목을 가장 긴 내용 기준의 공통 글자 크기로 자동 맞춤
- 개체 드래그 및 우하단 핸들을 이용한 크기 조절
- 5% 격자와 다른 개체의 경계·중앙선에 맞추는 자석 스냅 및 점선 가이드
- `Ctrl`/`Cmd`를 누른 상태에서 여러 개체 선택 및 함께 이동
- 선택한 개체를 `Ctrl+C`/`Cmd+C`로 복사하고 `Ctrl+V`/`Cmd+V`로 붙여넣기
- 개체를 선택하지 않은 상태에서는 현재 본문 페이지를 `Ctrl+C`/`Cmd+C`로 복사하고 현재 페이지 뒤에 `Ctrl+V`/`Cmd+V`로 붙여넣기
- `Ctrl+Z`/`Cmd+Z` 되돌리기
- 한 페이지에 여러 이미지 삽입
- 개조식 항목의 `Tab`/`Shift+Tab` 위계 조정, 위계별 공통 글자 크기 자동 맞춤 및 한글 단어 단위 줄바꿈
- 레이아웃·다이어그램 항목 추가·삭제 시 기존 텍스트와 서식을 유지하고 남은 카드 폭을 가용 영역에 맞게 자동 재배치
- 마인드맵 4단계 계층, 방사형 배치, 부모–자식 연결선 및 단계별 색상
- 마인드맵 항목 추가·삭제 시 기존 노드 위치 유지
- 테이블 레이아웃의 행·열 추가 및 삭제
- 꼭짓점이 삼각형인 1단계를 포함하는 피라미드 다이어그램
- 전체 화면 프레젠테이션 보기 및 `←`·`→` 키를 이용한 이전·다음 슬라이드 이동
- 전체 프로젝트를 JSON 형식의 `.txt` 파일로 저장하고 다시 불러오기

## 레이아웃, 다이어그램과 차트

개체형 템플릿을 선택하면 레이아웃, 다이어그램, 차트 및 그래프를 접이식 썸네일 목록에서 미리 보고 선택할 수 있습니다.

| 레이아웃 | 구성 |
|---|---|
| 카드형 그리드 2×2 | 테두리가 있는 복수 카드를 2열 중심의 격자로 배치 |
| 측면 강조 카드 1×3 | 세로 컬러 라인과 굵은 제목·설명으로 구성된 3열 카드 배치 |
| 테이블 | 헤더와 데이터 행으로 구성되며 행과 열을 독립적으로 추가·삭제할 수 있는 표 |
| 비교 패널 1×2 | 두 개념이나 전후 상태를 나란히 비교 |
| 상단 배너 + 지표 카드 1×4 | 전체 너비 배너 아래에 핵심 지표 카드를 배치 |
| 단계 카드 1×4 + 하단 미디어 | 단계 카드 아래에 이미지 또는 미디어 영역을 배치 |
| 메인 테이블 + 우측 지표 3×1 | 넓은 테이블 오른쪽에 세로 지표 카드를 배치 |
| 좌측 미디어 + 기능 카드 2×2 | 세로 미디어 영역 옆에 기능 카드를 격자로 배치 |
| 비교 패널 1×2 + 하단 결론 | 두 비교 패널 아래에 전체 너비의 결론 배너를 배치 |
| 수평 스케일 1×4 + 정의 카드 1×4 | 수평 기준점과 이에 대응하는 정의 카드를 함께 배치 |
| 프로세스 카드 1×7 + 안내 패널 2×1 + 1×1 | 가로 프로세스 카드와 두 개의 보조 패널, 하단 전체 안내를 배치 |
| 아이콘 카드 2×3 + 하단 안내 1×1 | 아이콘 정보 카드 그리드 아래에 전체 안내를 배치 |
| 테이블 5×3 + 안내 패널 1×2 | 행·열 관리가 가능한 테이블 아래에 두 개의 안내 패널을 배치 |
| 단계 카드 1×3 + 하단 안내 2×1 | 단계 카드 아래에 전체 너비 안내 두 개를 세로로 배치 |
| 개념 카드 1×3 + 안내 패널 1×2 + 1×1 | 개념 카드, 두 개의 안내 패널, 하단 전체 안내를 조합 |
| 상단 패널 1×2 + 기능 카드 1×4 + 하단 안내 1×1 | 두 개의 상단 개요 패널 아래에 기능 카드와 전체 안내를 배치 |
| 중앙 강조 패널 1×1 + 하단 카드 1×3 | 넓은 중앙 강조 패널 아래에 핵심 카드를 나란히 배치 |
| 측면 강조 카드 4×2 | 세로 강조선이 있는 정보 카드를 4행 2열로 배치 |
| 상단 체크 카드 1×3 + 하단 경고 카드 1×3 | 상단 점검 카드와 대응하는 하단 경고 카드를 같은 열에 배치 |
| 지표 상세 카드 2×2 + 하단 안내 1×1 | 별도 지표 영역이 있는 상세 카드와 하단 전체 안내를 배치 |

| 다이어그램 | 구성 |
|---|---|
| 프로세스 | 단계 노드를 직선으로 연결한 순차 흐름 |
| 타임라인 | 위아래로 교차하는 물결형 곡선과 화살표로 시간 흐름 표현 |
| 피라미드 | 삼각형 꼭짓점에서 시작해 단계가 내려갈수록 넓어지는 계층 구조 |
| 사이클 | 반복되는 단계를 원형으로 연결한 순환 구조 |
| 사슬형 | 연속된 항목을 사슬처럼 연결한 관계 구조 |
| 리본 화살표 | 방향성이 있는 리본 조각으로 구성한 진행 단계 |
| 미니멀 깔때기 | 단계가 진행될수록 폭이 좁아지는 수렴 구조 |
| 벤 다이어그램 | 2~4개의 겹치는 원으로 공통 영역 표현 |
| 과녁·동심원 | 중심으로 가까워지는 목표와 우선순위 표현 |
| 연결된 원형 | 중앙 주제와 주변 항목을 방사형으로 연결 |
| 사분면 | 네 영역으로 정보를 비교하고 분류하는 고정 구조 |
| VS | 두 대상을 좌우에 배치하는 고정 비교 구조 |

측면 강조 카드는 기본 3열로 생성되며 항목이 늘어나면 다음 행으로 자동 배치됩니다. 타임라인은 기본 5단계로 생성되고 각 구간의 제목과 설명을 두 줄로 직접 편집할 수 있습니다. 사분면은 4개, VS는 2개로 고정되며 나머지 다이어그램은 구조별 허용 범위 안에서 항목을 추가·삭제할 수 있습니다.

| 우선순위 | 차트 및 그래프 | 용도 |
|---|---|---|
| 1 | 세로 막대 차트 | 범주별 수치 비교 |
| 2 | 선 차트 | 시간 또는 순서에 따른 변화 추이 |
| 3 | 원형 차트 | 전체 대비 구성 비율 |
| 4 | 가로 막대 차트 | 순위 비교 또는 긴 항목 이름 |
| 5 | 영역형 차트 | 시간에 따른 변화량과 규모 |

차트 아래에는 항목별 숫자 입력란이 표시됩니다. 왼쪽의 `+ 데이터`와 `− 데이터` 버튼으로 항목을 2~8개까지 조정할 수 있으며 새 항목은 현재 데이터의 평균값으로 추가됩니다. 값을 수정하면 막대 높이, 선과 영역의 좌표, 원형 차트의 비율이 즉시 다시 계산됩니다. 숫자는 0 이상 1,000,000 이하로 제한되며 추가·삭제와 값 변경은 되돌리기 및 프로젝트 저장 파일에 포함됩니다.

기존 레이아웃이나 다이어그램을 차트로 변경하면 표 셀과 텍스트에서 숫자를 찾아 항목명·값 쌍으로 변환하고, 변환 전 문구는 차트 하단의 원문 영역에 함께 보존합니다. 차트 종류를 바꾸거나 다시 레이아웃·다이어그램으로 전환해도 저장된 원문과 데이터가 유지됩니다. 숫자가 없는 내용도 원문을 잃지 않으며, 이 경우 항목 존재를 동일 비중으로 시각화합니다. 누적 차트, 혼합형 차트, 분산형 차트처럼 다중 계열이나 별도 축 설정이 필요한 유형은 현재 포함하지 않습니다.

## 실행 방법

### 권장 실행 방법

1. 저장소를 내려받거나 복제합니다.
2. Node.js 18 이상에서 로컬 서버를 실행합니다.
3. Chrome 또는 Edge에서 `http://127.0.0.1:8765`를 엽니다.

```bash
git clone https://github.com/xoruddkqk4-glitch/local_ppt_2.git
cd local_ppt_2
node server.js
```

서버는 `127.0.0.1`에만 연결되며 별도의 패키지 설치나 빌드 과정은 없습니다.

Windows에서는 프로젝트 폴더의 `start-local-ppt.cmd`를 더블클릭하면 됩니다. 실행 파일은 8765 포트의 기존 서버를 재사용하거나 새 서버를 최소화된 창으로 시작한 뒤, 기본 브라우저에서 `http://127.0.0.1:8765`를 자동으로 엽니다.

다른 Windows 컴퓨터로 옮길 때는 프로젝트 폴더의 파일을 그대로 복사하거나 압축해 이동하면 됩니다. `.git` 폴더는 실행에 필요하지 않습니다. 대상 컴퓨터에 Node.js 18 이상이 설치되어 있어야 하며, AI API와 Pretendard·PDF.js·SheetJS CDN을 사용하려면 인터넷 연결이 필요합니다. 폴더 위치나 이름이 달라도 `start-local-ppt.cmd`가 자신의 위치를 기준으로 서버를 시작합니다.

### 편집기만 사용

AI 생성 기능 없이 편집기만 사용한다면 `index.html`을 직접 열 수 있습니다. 이 경우 빈 슬라이드와 기존 프로젝트 불러오기·편집·저장 기능은 사용할 수 있지만 `/api/generate`가 없으므로 AI PPT 생성은 동작하지 않습니다. Pretendard 웹폰트와 PDF·엑셀 분석 도구는 jsDelivr CDN에서 불러옵니다.

페이지를 복사하면 텍스트, 이미지, 개체 위치와 크기, 마인드맵 연결을 포함한 페이지 전체가 복제됩니다. 붙여넣은 페이지는 현재 페이지 바로 뒤에 삽입되며 자동으로 선택됩니다. PAGE 01은 프레젠테이션의 고정 표지이므로 페이지 복사 대상에서 제외됩니다.

## 항목 추가 및 삭제

표지에서는 선택 없이 새 텍스트 항목을 추가할 수 있습니다. 본문에서는 항목 개체를 하나 선택해야 왼쪽 패널의 `+ 항목`과 `− 항목` 버튼이 활성화됩니다. 테이블 레이아웃에서는 표를 별도로 선택하지 않아도 행·열 관리 기능을 사용할 수 있습니다.

- 표지: 도형 없는 텍스트 항목을 추가합니다. 항목을 선택한 뒤 `Tab` 또는 `Shift+Tab`으로 위계를 조정할 수 있습니다.
- 개조식: 선택한 항목 다음에 새 항목을 추가하거나 선택한 항목을 삭제합니다. `Tab`은 하위 위계, `Shift+Tab`은 상위 위계로 변경합니다. 동일 위계의 항목은 가장 긴 내용을 기준으로 같은 글자 크기를 사용하며, 위계가 내려갈수록 글자 크기가 작아집니다.
- 마인드맵: 선택한 노드에 하위 가지를 추가합니다. 4단계에서는 더 깊은 가지를 추가할 수 없습니다. 가지를 삭제하면 그 아래의 모든 하위 가지도 함께 삭제됩니다. 추가와 삭제는 나머지 노드의 위치에 영향을 주지 않습니다. 같은 단계의 노드는 가장 긴 문구가 들어가는 공통 글자 크기를 사용합니다.
- 테이블: 테이블 레이아웃에서만 표시되는 `테이블 관리 대상`에서 행 또는 열을 선택한 뒤 해당 방향으로 추가·삭제합니다.
- 레이아웃 및 다이어그램: 선택 상태를 기준으로 항목 수를 조정합니다. 항목을 추가하거나 삭제해도 기존 제목·카드·보조 패널의 텍스트와 서식은 유지됩니다. 카드 수가 줄면 고정된 빈 열을 남기지 않고 가용 영역을 다시 나누어 남은 카드의 폭을 확장합니다.

일반 레이아웃·다이어그램의 같은 역할 항목과 표의 모든 셀도 가장 긴 내용을 기준으로 공통 크기를 계산합니다. 한 항목의 글자 크기를 수동으로 변경하면 같은 역할·위계의 항목에도 함께 적용됩니다.

## 프로젝트 저장 파일

상단의 세 버튼으로 프로젝트를 관리할 수 있습니다.

- `txt 불러오기`: Local PPT 2 `.txt` 또는 `.json` 프로젝트 열기
- `현재 txt에 저장`: 현재 연결된 파일에 저장
- `다른 이름으로 저장`: 새로운 `.txt` 파일로 저장

저장 파일은 사람이 읽을 수 있도록 들여쓰기된 JSON이며 다음 정보를 포함합니다.

- 선택한 디자인
- 모든 페이지와 템플릿 정보
- 개체의 위치와 크기
- 텍스트 내용과 서식
- 마인드맵 계층 관계
- Base64 형식으로 포함된 이미지

Chrome과 Edge에서 File System Access API를 사용할 수 있으면 txt 불러오기와 다른 이름으로 저장이 동일한 Local PPT 2 전용 최근 폴더를 기억합니다. API를 사용할 수 없는 브라우저에서는 파일 입력 및 다운로드 방식으로 대체됩니다.

> 저장 파일에는 이미지 데이터도 포함되므로 이미지를 많이 삽입하면 `.txt` 파일 크기가 커질 수 있습니다.

## 브라우저 지원

최신 Chrome 또는 Edge 사용을 권장합니다. 두 브라우저에서는 File System Access API를 이용해 현재 파일에 바로 저장하고, `txt 불러오기`와 `다른 이름으로 저장`에서 최근에 사용한 폴더를 공유할 수 있습니다.

Firefox와 Safari에서도 기본 편집 및 다운로드 방식의 저장을 사용할 수 있지만, 브라우저 정책에 따라 현재 파일 덮어쓰기와 최근 폴더 기억 기능은 제한될 수 있습니다.

## 데이터와 개인정보

수동 편집 내용과 Local PPT 프로젝트 파일은 브라우저 메모리와 사용자가 선택한 로컬 `.txt` 파일에서 처리됩니다. AI PPT 생성을 실행하면 사용자가 선택한 입력 내용과 API 키가 로컬 중계 서버를 거쳐 선택한 AI 제공자(OpenAI 또는 Anthropic)로 전송됩니다. API 키는 브라우저 저장소, 프로젝트 파일 또는 서버 파일에 기록되지 않으며, 생성 성공 후 입력란에서도 제거됩니다. 실패한 경우에는 오류를 확인하고 다시 시도할 수 있도록 입력란에 유지됩니다. PDF와 엑셀은 브라우저에서 텍스트로 추출되며, 추출된 텍스트만 AI 생성 요청에 포함됩니다.

## AI PPT 시작 화면

AI 생성은 OpenAI 또는 Anthropic API 키를 한 개 이상 입력해 슬라이드 장수(2~30장)에 맞추어 초안을 만듭니다. 키는 브라우저 저장소, 프로젝트 txt, 서버 파일에 기록되지 않으며, 로컬 주소(`127.0.0.1`)에만 열린 중계 서버가 요청 처리 후 즉시 버립니다. 인트로 화면은 기본 Bauhaus 디자인으로 시작하며, AI가 만든 데크도 Bauhaus 디자인을 사용합니다.

프레임워크나 별도 npm 패키지 설치 없이 실행할 수 있으며, AI 기능을 사용할 때만 Node.js 18 이상이 필요합니다.

## 최근 기능 업데이트 및 개선 사항

### 1. 디자인 & 테마 스타일 설정 레이아웃 및 썸네일 고도화
- **좌우 2컬럼 레이아웃 배치**: 좌측 컬럼에 `프레젠테이션 전체 디자인` 드롭다운과 `커스텀 테마 색상 (3가지)` 픽커를 세로로 나열하고, 우측 컬럼 전체에 선택한 디자인의 대형 미리보기 썸네일을 배치했습니다.
- **좌우 세로 높이 자동 맞춤**: `align-items: stretch` 및 Flexbox를 적용하여 좌측 커스텀 색상 카드와 우측 썸네일 카드의 하단 테두리가 일직선으로 맞춰지도록 UI 정렬을 개선했습니다.
- **실제 개조식 디폴트 화면 썸네일 연동**: 썸네일을 에디터의 실제 개조식 본문 슬라이드 화면(중앙 상단 대형 제목 **'핵심 메시지'** 및 두툼한 세로 강조선이 있는 **'첫 번째/두 번째/세 번째 핵심 내용'** 항목)과 100% 동일하게 구현했습니다. 선택한 10종 디자인 테마(`Bauhaus`, `Controlled Neo-Brutalism`, `Claymorphism`, `Swiss` 등)의 전용 스타일이 썸네일 프레임에 실시간 반영됩니다.

### 2. 6개 고정 위치 설정 (Fixed Overlays) 기능 및 UI 전면 개편
- **세련된 모던 카드 UI 개편**: 6개 위치 설정 카드(`overlay-config-card`)를 라운딩 테두리, 미세 그림자, 슬레이트 톤 모노스페이스 위치 태그 바지(`Top-Left`, `Top-Right` 등)로 현대적인 모던 디자인 시스템을 적용했습니다.
- **4종 입력 선택 드롭다운 (무입력, 페이지 정보, 날짜 정보, 이미지 추가)**:
  - **무입력**: 텍스트 및 이미지를 모두 초기화합니다.
  - **페이지 정보**: 동적 페이지 번호 토큰 `{page} / {total}` (예: `1 / 5`)이 자동 지정됩니다.
  - **날짜 정보**: 동적 날짜 토큰 `{date}` (예: 오늘 날짜 `2026-08-29`)가 자동 지정됩니다.
  - **🖼️ 이미지 추가**: 클릭 시 바로 이미지 파일 선택 창이 열려 기업 로고나 워터마크 이미지를 6개 고정 위치에 업로드하여 슬라이드에 렌더링할 수 있습니다.
- **스마트 이미지 미리보기 토글**: 이미지가 실제로 업로드된 경우에만 썸네일 박스가 노출되며, 텍스트 모드 및 평소에는 깨진 엑박 미리보기 상자가 100% 숨겨지도록 디스플레이 로직을 정밀화했습니다.
- **Title PAGE 01 (표지) 적용 여부 토글**: 표지 슬라이드 고정 문구/이미지 노출 여부 선택 옵션을 제공합니다.

### 4. 항목 개체 복수 선택 삭제 및 레이아웃 제약 제거
- **복수 선택 개체 일괄 삭제 (`- 항목`)**: `Ctrl`/`Cmd` 클릭 또는 영역 선택으로 다중 선택된 모든 항목 개체들을 **`- 항목`** 클릭 한 번으로 동시에 삭제하는 기능을 구현했습니다. (표지, 개조식, 마인드맵, 개체형 레이아웃/다이어그램 전면 지원)
- **삭제 최소 제한 제거 및 상시 활성화**: 레이아웃 및 다이어그램의 최소 개수 제약으로 인한 버튼 비활성화를 제거하여, 개체가 하나 이상 선택되어 있으면 **`- 항목`** 버튼이 항상 즉시 활성화됩니다.

### 5. 개체형 템플릿 11종 체계화 및 신규 대칭 레이아웃 추가
- **11개 핵심 레이아웃 체계화**: 중복 레이아웃을 정리하고 5개 카테고리 (그리드&카드, 비교&대조, 지표&배너, 프로세스&단계, 테이블&데이터) 기준 11개 고품질 레이아웃으로 개편했습니다.
- **신규 '지표 카드 1×4 & 하단 배너' (`metricsBottomBanner`) 추가**: 상단 배너 레이아웃과 대칭을 이루는 신규 지표/배너 레이아웃을 추가하고 AI 자동 생성 스키마에 동시 연동했습니다.
- **개체형 하위 서브메뉴 상시 노출**: 개체형 템플릿 선택 시 레이아웃, 다이어그램, 차트 및 그래프 3개 서브메뉴가 항상 빠짐없이 노출되어 원클릭으로 전환할 수 있습니다.

### 7. 카드 개체 이미지 자유 삽입 및 1~4열 전용 카드 그리드
- **모든 일반 카드의 자유로운 이미지 첨부**: 카드형 그리드, 측면 강조 그리드 등 모든 일반 카드가 텍스트 입력과 함께 개별 이미지를 삽입/수정/제거할 수 있도록 고도화했습니다. (불필요한 고정 미디어 레이아웃 완전 정리)
- **1열~4열 기본 및 측면 강조 카드 그리드**: `기본 카드 1~4열 그리드` 및 `측면 강조 카드 1~4열 그리드` 총 8종의 카드 전용 그리드 템플릿을 신규 개편하고, 2열 사이드바 교차 정렬 및 고화질 개별 시각 썸네일을 제공합니다.

### 8. 동일 위계 항목 일괄 병합 (단축키 `M` & 병합 버튼)
- **이웃 카드 일괄 병합 기능**: 캔버스에서 `Ctrl` / `Cmd` 키로 2개 이상의 이웃 개체를 다중 선택한 후 단축키 **`M`**을 누르거나 사이드바의 **`🧩 카드 합치기`** 버튼을 클릭하면 하나로 통합합니다.
- **동일 위계 검증 수식**: 선택된 카드들이 동일한 단계/위계(`bulletLevel`, `mindLevel`, 동일 구조 역할)에 위치할 때만 병합을 허용하여 구조적 무결성을 유지합니다.

### 9. '요약 및 강조' 템플릿 개편 및 방향별 4종 제공
- **'요약 및 강조' 카테고리 전환**: 기존 '비교 & 지표' 카테고리를 `📁 요약 및 강조`로 명칭 변경하고 전용 썸네일로 가시성을 확보했습니다.
- **방향별 요약 템플릿 4종**: `왼쪽 요약`, `오른쪽 요약`, `위쪽 요약`, `아래쪽 요약` 템플릿을 제공하여 다크 요약 패널 및 배너의 위치를 자유롭게 선택할 수 있습니다.

### 11. 사이드바 섹션 구조 개편 (`02 개체 관리`, `03 개체 삽입`, `? 도움말`)
- **섹션 레이아웃 수평 가로 정렬**: 숫자/기호 뱃지(`01`, `02`, `03`, `?`)와 제목 텍스트가 동일한 수평 가로 줄(Side-by-side)에 직관적으로 배치되도록 패널 헤딩 레이아웃을 정돈했습니다.
- **`02 개체 관리` & `03 개체 삽입` & `? 도움말` 독립 분리**: 캔버스 작업 영역 기능과 안내 영역을 역할별 독립 섹션으로 분리하고 파란색 도움말 뱃지를 도입했습니다.

### 13. AI 슬라이드 검토 & 템플릿 선택 모달 및 스타일 설정 모달 자동 연동
- **AI 생성 전 슬라이드 검토 모달 (`aiReviewModal`)**: AI로 슬라이드 생성 시 캔버스에 직접 반영되기 전에 생성된 슬라이드 제목과 내용을 미리 검토하고, 슬라이드별로 반영할 템플릿을 33종 전체 목록 중 자유롭게 변경할 수 있습니다.
- **스타일 모달 자동 오픈 연동**: 검토 모달에서 확인 클릭 시 슬라이드가 일괄 생성되며, 즉시 디자인 & 테마 스타일 설정 모달(`styleConfigModal`)이 열려 10종 디자인 테마와 색상을 적용할 수 있습니다.

### 14. 37종 전체 템플릿 간 내용 보존 전환 (`applyTemplatePreservingContent`)
- **데이터 완전 보존 템플릿 전환**: 개조식, 마인드맵, 카드 그리드, 요약 패널, 다이어그램, 데이터 차트/표 등 37종 전체 템플릿 간 자유롭게 변경하더라도 슬라이드 제목, 본문 텍스트, 카드 데이터, 첨부 이미지가 손실 없이 100% 보존됩니다.

### 15. 서식 툴바 테마 3색 퀵 선택 스위치 & 빈 도형 생성
- **테마 3색 퀵 칩 버튼**: 상단 개체 서식 툴바의 배경색 선택 영역 옆에 현재 디자인 테마의 1·2·3순위 색상 스와치 버튼 3종을 배치하여 원클릭으로 테마색을 반영합니다.
- **순수 도형 개체 생성**: 도형 삽입 시 불필요한 기본 임시 텍스트를 제거하고 텍스트 없는 순수 도형으로 깔끔하게 생성됩니다.

### 16. 연결선 애니메이션 순서 동기화 & 마인드맵 직속 부모-자식 정밀 연결
- **연결선 애니메이션 동기화**: 마인드맵, 다이어그램 연결선 및 타임라인 곡선이 연결 대상 개체의 애니메이션 순서(`animOrder`)를 동적 상속받아 발표 모드에서 동시에 등장합니다.
- **마인드맵 직속 부모-자식 연결**: 2단계를 건너뛰는 중복 연결선을 차단하고 오직 직속 상위 ↔ 직속 하위 노드 간에만 선이 명확히 연결됩니다.

### 17. 상단 페이지 탭 드래그 앤 드롭 순서 변경 및 Title PAGE 01 순서 유연화
- **상단 페이지 탭 드래그 앤 드롭 재정렬**: 상단 툴바의 모든 페이지 탭(`PAGE 01`, `PAGE 02` 등)에 HTML5 Drag & Drop 기능을 적용하여 마우스 드래그로 슬라이드 순서를 직관적으로 변경할 수 있습니다.
- **실시간 드래그 가이드 피드백**: 드래그 위치에 따라 이동 예정 위치(왼쪽/오른쪽)에 고대비 파란색 가이드 라인(`drag-over-before`, `drag-over-after`)과 반투명 탭 피드백을 제공합니다.
- **Title PAGE (표지) 위치 유연화**: 표지 슬라이드(`TITLE PAGE 01`)의 디폴트 위치는 첫 번째이지만, 사용자가 원하는 임의의 위치(2번째, 3번째 등)로 드래그하여 이동시키거나 다른 본문 슬라이드를 표지 앞으로 배치할 수 있습니다.
- **상태 및 프로젝트 저장 호환성**: 슬라이드 순서 변경 시 현재 작업 중인 슬라이드의 포커스가 유지되며, `Ctrl Z` 되돌리기 지원 및 저장 파일 불러오기(`parseProject`) 시 임의 위치의 표지 슬라이드 프로젝트도 안전하게 파싱됩니다.

### 18. 디자인 & 스타일 모달 표지 고정 문구 적용(applyToTitle) 버그 수정
- **디자인 모달 표지 고정 문구 적용 동기화**: 디자인 & 스타일 변경 모달에서 `Title PAGE 01 (표지)에도 적용` 체크박스 및 고정 이미지 설정을 읽고 적용하는 `getModalFixedOverlays()`, `setModalFixedOverlays()` 수집 로직을 보완하여 표지에 고정 레이어가 정상적으로 렌더링되도록 수정했습니다.

### 19. 페이지 드래그 앤 드롭 순서 변경 보완 및 Chrome 이벤트 억제 해결
- **버튼 태그 이벤트 억제 우회**: Chromium 계열 브라우저에서 `<button draggable="true">` 폼 컨트롤 고유 동작으로 드롭 이벤트가 취소되던 문제를 `<div class="page-item" role="button" tabindex="0">` 구조로 변경하여 해결했습니다.
- **포인터 추적 이중 드래그 시스템**: HTML5 Drag & Drop과 마우스 포인터 위치 추적(`elementFromPoint`)을 조합한 듀얼 모드로 브라우저 환경에 관계없이 100% 드롭 순서 변경을 보장합니다.
- **Target Dead Zone 제거**: 50% 반쪽 데드존을 없애고 `reorderPages(fromIndex, targetIndex)` 로직을 단순화하여 드롭한 타겟 슬라이드 위치로 즉시 재배치되도록 개선했습니다.

### 20. 페이지 숨김 (Page Hide) 기능 및 발표 스킵 연동
- **페이지 숨김 토글 버튼 (`👁` / `🙈`)**: 각 슬라이드 탭에 숨김 아이콘 버튼을 추가하여 클릭 한 번으로 숨김 상태를 전환할 수 있습니다. 숨겨진 페이지는 반투명 0.55, 취소선, 점선 테두리 및 `(숨김)` 표시가 부여됩니다.
- **고정 오버레이 페이지 번호 제외**: 하단 `{page} / {total}` 동적 토큰 계산 시 숨겨진 페이지를 완전히 제외하고 유효 발표 슬라이드만 카운트합니다.
- **전체 화면 발표 모드 스킵**: Fullscreen 발표 모드에서 마우스 및 키보드(`←`, `→`, Space) 이동 시 숨겨진 슬라이드를 자동으로 건너뜁니다.

### 21. 텍스트 개체 테두리 서식 편집 기능
- **서식 툴바 테두리 조작 컨트롤**: 상단 개체 서식 툴바에 테두리 색상 선택기(`borderColorInput`), 테두리 두께(0~20px), 선 모양(실선, 점선, 이중선 등) 조작 컨트롤을 추가했습니다.

### 32. 타이머 개체 시간/글자크기 단축키, 쉬는 시간 설정, Pretendard 폰트 및 발표 모드 완벽 통합
- **단축키를 이용한 타이머 시간/글자 크기 미세 조절 ([Shift + 방향키], [Ctrl + 위/아래 방향키])**:
  - **[Shift + 방향키]**: 편집 화면에서 타이머 선택 상태이거나 전체 화면 발표 진행 중일 때 방향키로 타이머 시간을 즉시 조절할 수 있습니다. (`Shift + Right`: +10초, `Shift + Left`: -10초, `Shift + Up`: +1분, `Shift + Down`: -1분)
  - **[Ctrl + 위/아래 방향키]**: 시간 숫자 크기를 10% 단위로 미세 확대/축소(`timerFontSizeScale`)할 수 있습니다. (최대 크기는 타이머 카드 영역을 벗어나지 않도록 clamp 조정)
  - **좌측 패널 도움말 탑재**: `? 도움말 & 단축키 안내` 섹션에 타이머 개체 전용 단축키 가이드를 명확히 명시했습니다.
- **루프 타이머 간 쉬는 시간 (Rest Duration) 및 'Time's up!' 표시**:
  - 루프 타이머 상단 헤더에 **쉬는 시간(초)** 입력란(`restSeconds`, 기본값 1초)을 추가했습니다.
  - 타이머 카운트다운이 완료되면 **'Time's up!'** 문구를 표시하며, 루프 반복 시 지정한 쉬는 시간 동안 화면에 노출된 뒤 다음 루프로 자동 전환됩니다.
  - `Time's up!` 9자 긴 문구가 카드 너비를 벗어나지 않도록 컨테이너 쿼리 너비 제약(`min(28cqh, 10cqw)`) 및 자동 폰트 감축 로직을 적용했습니다.
- **디자인 무관 동일 기본 색상 (하얀색 배경 & 검정색 숫자)**:
  - 타이머 추가 시 PPT 디자인 테마에 상관없이 기본 배경색은 **하얀색 (`#ffffff`)**, 숫자 텍스트는 **검정색 (`#000000`)**으로 고정 설정됩니다.
  - 흰색 배경 카드에 맞추어 헤더 라벨, 모드 선택 드롭다운, 숫자 입력란, 추천 시간 프리셋 버튼(1분~30분) 및 리셋 버튼의 테두리와 텍스트 색상을 다크 슬레이트 톤으로 깔끔하게 디테일링했습니다.
- **숫자 텍스트 굵은 Pretendard 폰트 적용**:
  - 시간 숫자 디스플레이의 글씨체를 **굵은 Pretendard (`font-weight: 900`, Pretendard Variable)**로 설정하여 또렷하고 세련된 시독성을 확보했습니다.
- **선택 상태 및 발표 모드에 따른 상단 헤더 메뉴 동적 토글**:
  - **미선택 상태 (기본/발표 모드)**: 모드 선택, 반복, 쉬는 시간 및 추천 시간 버튼(1분~30분) 상단 메뉴가 자동으로 숨겨지고 **디지털 시간 숫자, '▶ 시작 / ⏸ 일시정지' 버튼, '🔄 리셋' 버튼만 깔끔하게 노출**됩니다.
  - **선택 상태 (편집 모드)**: 타이머 개체를 클릭하면 상단 설정 메뉴가 노출되어 모드 및 프리셋을 자유롭게 수정할 수 있습니다.
- **전체 화면 발표 모드(Fullscreen) 선택 테두리 제거 및 컨트롤 클릭 버그 수정**:
  - **선택 점선 테두리 수프레스**: 발표 모드 진입 시 `:fullscreen` CSS 규칙 및 `state.selectedIds.clear()`를 적용하여 파란 점선 선택 테두리와 크기 조절 핸들이 발표 화면에서 완전히 숨겨집니다.
  - **타이머 컨트롤 클릭 반응성 보장**: 기존 발표 모드의 스테이지 클릭 캡처(Capture Phase) 핸들러가 타이머 버튼 클릭 이벤트를 차단하던 문제를 해결하여, 전체 화면 발표 중에도 '▶ 시작 / ⏸ 일시정지' 및 '🔄 리셋' 버튼이 즉시 원활하게 동작합니다.

### 33. PPT 프로젝트 txt 저장 시 업로드 이미지 텍스트 인코딩 저장 및 컴퓨터 로컬 시간 파일명 적용
- **이미지 Base64 Data URL 인코딩 저장**: 슬라이드에 포함되거나 드래그 앤 드롭으로 첨부된 이미지는 Base64 텍스트 문자열로 변환되어 `.txt` (JSON) 프로젝트 파일 내에 자동 보관되며, 파일을 로드할 때 원본 그대로 100% 복원됩니다.
- **컴퓨터 로컬 시간 기반 파일명 자동 생성**: 프로젝트를 txt로 저장할 때 사용자의 현지 컴퓨터 시간(24시간제)을 반영하여 `local-ppt_YYYY-MM-DD_HH-mm-ss.txt` 형식의 유일한 추천 파일명이 자동 부여됩니다.
- **`현재 txt에 저장` 버튼 동적 애니메이션 & 토스트 알림 탑재**:
  - 저장 버튼 클릭 시 `💾 저장 중...` 로딩 표시에 이어 `✅ 저장 완료!` 문구와 초록색 확장 펄스 애니메이션이 실행됩니다.
  - 저장 완료 시 화면 우측 하단에 성공 토스트 알림 팝업(`save-toast-notification`)이 부드럽게 나타나 저장된 파일명을 확인시켜 줍니다.

### 34. 이미지 레이아웃 내 첨부 이미지 개체 Del 키 삭제 및 카드 첨부 이미지 1차 삭제 지원
- **Del / Backspace 키 이미지 개체 삭제**: 이미지 레이아웃(`image_full`, `image_center`, `image_left`, `image_right`, `image_top`, `image_bottom`)에서 이미지 개체 선택 후 `Del` 키 입력 시 텍스트 카드 개수를 감소시키거나 이미지를 재생성하지 않고 해당 이미지 개체만 정확히 삭제 처리합니다.
- **`page.imageDeleted` 상태 추적 및 보존**: 이미지 삭제 상태를 추적하여 템플릿 변경이나 텍스트 카드 수정/재구성이 발생하더라도 지워진 이미지가 다시 복구되는 현상을 완벽 방지했습니다.
- **카드 첨부 이미지(`imageSrc`) 1차 삭제 지원**: 카드 개체에 첨부된 이미지가 존재하는 경우 `Del` 키 입력 시 카드 텍스트 상자는 유지하면서 첨부 이미지(`imageSrc`)만 1차로 삭제되며, 한 번 더 `Del` 키를 누르면 카드 전체가 삭제됩니다.

### 35. Title PAGE 01 스타일 변경 모달 내 고정 문구 렌더링 참조 오류 수정
- **`renderFixedOverlayLayer` 변수 참조 오류 해결**: 고정 위치 레이어 렌더링 시 `rawText` 변수의 미선언으로 인해 발생하던 자바스크립트 예외(`ReferenceError: rawText is not defined`)를 수정했습니다.
- **표지 및 본문 고정 문구 렌더링 정상화**: Title PAGE 01 스타일 변경 모달에서 'Title PAGE 01 (표지)에도 적용' 체크 및 6개 위치별 고정 문구 설정 시 표지와 본문 슬라이드에 고정 문구가 멈춤 없이 즉시 반영되도록 처리했습니다.

### 36. 개체 텍스트 항시 세로 중앙 정렬 보장 및 유령 갭 제거
- **세로 정렬 오버라이드 수정**: `applyTextObjectStyle`에서 가로 정렬(`left`) 적용 시 `justifyContent`가 `flex-start`로 설정되어 Flexbox column 구조에서 텍스트가 상단으로 쏠리던 문제를 `justifyContent = "center"`로 고정하여 정렬 옵션에 상관없이 텍스트가 항상 세로 중앙에 오도록 조치했습니다.
- **빈 자식 요소로 인한 유령 갭 제거**: `renderObject` 렌더링 시 내용이 없는 빈 헤딩 및 설명 요소(`<span>`)가 생성되어 텍스트 위치를 위로 밀어내던 현상을 수정하여 편집 중/미선택 상태 모두 동일하게 100% 세로 중앙 정렬을 유지합니다.

### 37. 편집 화면 하단 불필요한 거대 빈 공간 제거 및 레이아웃 반응형 개선
- **오른쪽 캔버스 뷰포트 반응형 중앙 정렬 (`.stage-panel`, `.presentation-stage`)**: `.stage-panel`을 세로 중앙 정렬(`justify-content: center`)로 변경하고 `.presentation-stage`에 반응형 높이 제약(`calc((100vh - 150px) * 1.7777)`)을 적용하여 16:9 슬라이드가 해상도에 맞게 수용되고 캔버스 하단에 불필요한 거대한 빈 여백 공간이 남지 않도록 보완했습니다.
- **사이드바 레이아웃 갤러리 영역 스크롤 고정 (`.layout-variant-grid`)**: 이미지 레이아웃(6종 썸네일) 등 서브 메뉴를 펼치더라도 사이드바 전체가 과도하게 늘어나지 않도록 내부 스크롤(`max-height: 340px; overflow-y: auto;`)을 부여하여 안정적인 편집 화면을 구성했습니다.

### 38. 개체 테두리 두께 0 / 선 없음 설정 시 테두리 완전 숨김 처리
- **인라인 `border: none` 강제 적용**: 상단 개체 서식 툴바에서 두께 `0` 또는 선 모양 `없음(none)` 선택 시 `wrapper.style.border = "none"`을 설정하여 CSS 클래스에 정의된 기본 테두리 스타일이 덮어씌워져 보이는 현상을 완전히 해결했습니다.
